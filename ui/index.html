    This server doesn't share vending machines

    Right now this server sends Recon no shops at all, so there's nothing to search or show on the map.

    Why?
    • Recon (like every Rust+ app) can only see what the server shares through Rust+. Some servers turn this off on purpose so nobody can scan every shop from outside the game.
    • Only player vending machines with Broadcast turned on are ever shared. Outpost and Bandit Camp vendors never are.
    • Early in a wipe there may simply be no broadcasting shops yet.
    What you can do
    • Use the vending search on the in-game map (press G).
    • On servers that share shops, this tab works automatically: item search, best prices, shops on the map, and alerts for items you watch.
